ASP.CORE net10 web application made with C#, cshtml, css, js. Uses a simple MVC arhitecture.

The web application is about a turn-based game inspired from a childhood game Sports Heads: Cards Squad Swap (play at https://www.miniplay.com/game/sports-heads-cards-squad-swap). 
I remembered this old game and thought it would be fun to play it multiplayer against a friend, so I am making this web application.

The images for the cards are edited using [photopea](https://www.photopea.com/).
